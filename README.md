# Portfolio-live

Personal portfolio for Honorine Mugisha, a Computer Science student exploring web development and beginner IoT systems.

## Run locally

Open the folder with a local static server:

```powershell
py -m http.server 8000
```

Then visit <http://localhost:8000>.

## Update checklist

The following areas are intentionally easy to update:

1. **Contact:** email, WhatsApp, GitHub, and Vercel links in `index.html`.
2. **Projects:** replace the repository link with individual demo/repository URLs when available.
3. **Experience:** add an experience section when internship or volunteer details are ready.
4. **CV:** add a `cv.pdf` file and link it from the navigation or contact area.
5. **Social preview:** replace `og:image` with a deployed absolute image URL before launch.
6. **Deployment:** set the canonical deployed URL, sitemap, and robots policy after the Vercel deployment is confirmed.

## Deployment

The project is a static site and can be deployed to Vercel or GitHub Pages. Before publishing, verify the email, project links, public URL, and screenshots.
